# filelist

Before running commands, make sure your terminal is pointed at the RatLab directory.

`./Tools/list_files.sh` Generates a text file called 'filelist.txt' which will contain all the important file paths, located at './Misc/'

## Usage

Run the above command in the terminal to generate an updated version of the filelist text file.

## Steps

1. Run the above command in the terminal.
2. Wait for the command to finish (The command is usually really fast to finish.)
3. If all of the above steps are finished, then this skill is completed.

## Common Problems

- What if the command doesn't finish executing?
A very unlikely scenario- but if the command ever happens to not finish within 10 seconds of executing, then this problem is unsolvable and the user must be notified about this fatal error.
